# QAZCHEM LAB — виртуалды химия зертханасы

Қазақ тіліндегі интерактивті веб-қосымша: 10 зертханалық жұмыс, ғылыми есептеу моделі, 3D көрініс (WebGL жоқ болса — 2D/SVG), мұғалім конструкторы, 118 элементтік периодтық кесте, зертханалық дәптер, бағалау, экспорт/импорт.

Тіркелу жоқ. Деректер тек осы браузердің `localStorage` жадында сақталады; құрылғылар арасында синхрондалмайды. «Оқушы» / «Мұғалім» — интерфейс режимі, авторизация емес.

## Орнату және іске қосу

Қажет: Node.js 20+.

```bash
npm install
npm run dev            # әзірлеу сервері (Vite)
npm run build          # өндірістік жинақ → dist/
npm run preview        # жинақты жергілікті қарау
npm test               # ғылыми және дерек тесттері (30 тест)
npm run build:single   # бір HTML файл → dist-single/qazchem-lab.html
npm run e2e            # браузерлік тесттер (алдымен: npx playwright install chromium)
```

`dist/` немесе `dist-single/qazchem-lab.html` кез келген статикалық хостингке (GitHub Pages, Netlify, мектеп сервері) салынады. Маршрутизация хэш арқылы (`#/lab/titration`), сондықтан серверді баптау қажет емес.

> Ескерту: бұл жоба жиналған ортада npm реестріне қол жетпеді. Код жергілікті React 19.2 және esbuild арқылы жиналып, тексерілді (`build:single`, `test`, `e2e`). `package.json`-дағы Vite/TypeScript нұсқалары бекітілген, бірақ `npm install && npm run build` жолы осы ортада іске қосылмаған — бірінші орнатуда тексеріңіз.

## Құрылым

```
src/app            навигация, жалпы күй, хэш-маршрутизатор
src/pages          бөлімдер (басты бет, жұмыстар, зертхана, кесте, дәптер, нәтижелер, анықтама)
src/components     ортақ интерфейс (формула, теңдеу, кесте, график)
src/lab/engine     ғылыми есептеу моделі — 10 модель, таза функциялар, көріністен тәуелсіз
src/lab/scenes     WebGL рендерер, 3D зертхана/молекула/атом, 2D балама
src/data           118 элемент (scripts/gen_elements.py жасайды), 10 жұмыс шаблоны
src/builder        мұғалім конструкторы
src/assessment     бағалау ережелері
src/storage        сақтау, нұсқалау, JSON/CSV импорт-экспорт және тексеру
src/tests          ғылыми және дерек тесттері
scripts/           бір файлды жинақ, e2e тесттері, элементтер генераторы
```

Негізгі дерек құрылымдары: `ReactionModel`, `Equation`/`Species`, `Substance`, `ParamDef`, `ExperimentTemplate`, `StepDef`, `QuizItem`, `Attempt`, `MeasureRow`, `ElementData`. Реакциялар құрылымдалған деректер (коэффициент, фаза, заряд) ретінде сақталады; атомдар мен заряд балансы тестпен тексеріледі.

**3D туралы:** ортада Three.js пакетін орнату мүмкін болмады, сондықтан `src/lab/scenes/gl.ts` — шағын өз WebGL рендерері (жарық, мөлдір шыны, орбиталық камера). Ғылыми модель рендерерден бөлек болғандықтан, оны кейін Three.js/React Three Fiber-ге ауыстыру тек `labScene.ts` және `models3d.tsx` файлдарына қатысты.

## Оқушыға

1. «Жұмыстар» → жұмысты таңда → болжам жаса → «Тәжірибені бастау».
2. Сол жақтан құралдарды таңдап «Орналастыру» бас (немесе үстелге сүйреп апар).
3. Реактивтерді қос, қажет болса «Бастау / Үзіліс» арқылы процесті бақыла.
4. «Өлшеуді дәптерге жазу», бақылауыңды жаз — сонда түсіндірме ашылады.
5. Тапсырмаларды тексер, қорытынды жаз, «Жұмысты аяқтау».
6. «Дәптер»: есеп, CSV, JSON, екі әрекетті салыстыру.

## Мұғалімге

1. Жоғарыдан «Мұғалім» режимі.
2. «Құрастыру» → негізгі модельді таңдап «Жаңа шаблон» → мәтін, болжам, бастапқы шарттар (модель ауқымында), кезеңдер, тапсырмалар, салмақтар.
3. «Сақтау» әр жолы жаңа нұсқа жасайды; басталған жұмыстар өз нұсқасымен жалғасады. Жойылған шаблонды қайтаруға болады.
4. JSON экспорт → оқушы компьютерінде импорт.
5. «Нәтижелер» → «Бағалау»: ашық жауаптар мен қорытындыны рубрикамен бағалау.

## Орындалған тексерулер (30.10.2026)

- `npm run e2e` (Chromium, WebGL — SwiftShader): **65/65** — навигация, артқа/алға, 10 жұмыстың әрқайсысы, үзіліс кезінде күй өзгермеуі, қайта бастау, бет жаңартқанда қалпына келу, сүйреп апару, CSV/JSON экспорт, импорт (дұрыс және бүлінген), мұғалім рубрикасы, конструктор (сақтау, нұсқа, алдын ала қарау, жою/қайтару), 118 карточка, пернетақта, 2D режим, WebGL жоқ құрылғы, 360 px көлденең айналдырусыз, қозғалысты азайту, өңделмеген қате жоқ.
- Тексерілмегендер: экраннан оқу құралдарымен нақты сынақ; нақты планшет/телефон; басып шығару нәтижесі (тек CSS); Vite жинағы (жоғарыдағы ескертуді қараңыз); офлайн жұмыс уәде етілмейді.

## Ғылыми модельдердің шектеулері (қысқаша)

- Барлық ерітінді модельдері — 25 °C, идеал (активтілік = концентрация).
- pH және титрлеу: күшті қышқыл/негіз, Kw ескеріледі; 0,1 моль/л-ден жоғары дәл емес.
- Фенолфталеин 8,2–10,0 (дереккөздерде 8,0–9,6 деп те беріледі).
- Тұнба: Ksp(CaCO₃) = 3,36·10⁻⁹; карбонат гидролизі ескерілмейді.
- Орынбасу, карбонат, катализатор: жылдамдық тек сапалық «шартты уақыт».
- Өткізгіштік: шартты салыстырмалы шкала, См/м емес.
- Ерігіштік: NaCl 36,0 г/100 г су (25 °C).
- Электролиз: Фарадей заңы, ток тиімділігі 100 %, газдардың еруі ескерілмейді.
- Элемент деректері CIAAW/IUPAC/NIST негізінде жасалды, бірақ онлайн салыстырылмады; Z ≥ 104 конфигурациялары болжамды. Химия мұғалімінің рецензиясы ұсынылады.

## Көп пайдаланушылы өндірістік кезеңге көшу жоспары

1. **Сервер және дерекқор:** PostgreSQL + API (мысалы, Node/NestJS немесе Supabase). `Attempt`, `ExperimentTemplate` құрылымдары өзгеріссіз кестелерге көшеді; `templateVersion` + шаблон көшірмесі қазірдің өзінде нұсқалауды қамтамасыз етеді.
2. **Аутентификация және рөлдер:** мектептік SSO немесе email; рөлдер (оқушы, мұғалім, әкімші) серверде тексеріледі; клиенттегі режим ауыстырғыш алынады.
3. **Сыныптар және тапсырма тарату:** сынып → оқушылар → тағайындалған шаблон нұсқасы, мерзімі.
4. **Синхрондау:** localStorage офлайн-кэш ретінде қалады; сервермен соңғы өзгеріс бойынша біріктіру, қақтығыс кезінде пайдаланушыға көрсету.
5. **Деректерді қорғау:** Қазақстанның дербес деректер туралы заңына сәйкестік, ата-ана келісімі, минималды дерек (лақап ат + сынып).
6. **Сапа:** CI-да `npm test` + `e2e`, a11y аудиті (axe), нақты құрылғыларда сынақ, химия мұғалімдерінің контент рецензиясы, PWA арқылы тексерілген офлайн режим.
